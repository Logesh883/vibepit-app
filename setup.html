Setup guide

Set up VibePit. Then let Claude work.

This guide takes you from the download to your first finished task with Claude Code. It explains each step in simple words, so you do not need any earlier experience with Claude Code. Most people are ready in about 10 minutes. You can also find this guide inside the app, under Setup guide.

Before you begin

Please check that you have the following. VibePit installs Claude Code for you if it is missing.

A Mac

macOS 12 or later. Apple silicon (M1 or later) or Intel.

A Claude account

An account that can use Claude Code: Pro, Max, Team or Enterprise, or an API key. VibePit uses your own account.

VS Code

Recommended. Each project opens in a VS Code window, with Claude in its terminal panel. You can use Terminal instead.

About 10 minutes

Most of this time is installing Claude Code and logging in. If you choose to talk to VibePit, the speech models also download once.

Which download do I need? Open the Apple menu and choose About This Mac. If the line Chip says Apple M1, M2, M3 or later, choose Apple silicon. If it says Processor and Intel, choose the Intel download.

1. Install VibePit

  1. Download the disk image for your Mac from the button above. The file is called VibePit-arm64.dmg (Apple silicon) or VibePit-x86_64.dmg (Intel).
  2. Open the disk image from your Downloads folder, and drag VibePit into the Applications folder.
  3. Open VibePit from Applications or Launchpad.
  4. Allow it to open, the first time only. macOS may say that it cannot check VibePit for malicious software. This is expected. Open System Settings → Privacy & Security, scroll down, press Open Anyway next to VibePit, and confirm. You only need to do this once.

2. Follow the Get started card

When VibePit opens, the Overview page shows a Get started card. It has one button for each remaining step. Each step ticks itself off when it is done, so you always know what is left.

Install Claude Code

If Claude Code is not on your Mac yet, press the button and VibePit installs it for you.

Log in to Claude Code

Press the button to log in with your Claude account. Your browser opens so that you can sign in safely with Claude. VibePit never sees your password.

Get VS Code

If VS Code is not installed, the button takes you to its download. VibePit then adds a small extension to VS Code, which lets it open named Claude tabs. If you prefer Terminal, choose Use Terminal instead.

Alerts from Claude Code

VibePit adds a small setting to Claude Code, so that it knows when Claude is working, done, or needs you. This is what puts Claude’s questions in the Chat. If the Overview says the alerts are missing, press Install alerts there.

Add your projects

The last step takes you to the Projects page. The next section explains it.

3. Add your projects

A project is a folder on your Mac with code in it. Each project gets a short name, such as abc, that you use to open it and send it messages.

Set up with Claude

On the Projects page, press Set up with Claude. VibePit finds the projects on your Mac and suggests a short name for each one. Tick the ones you want and press Add. Claude sees only the project names, their top-level files and their READMEs, and it cannot change anything.

Add one yourself

Press + New project, type a name, and choose its folder.

Settings for each project

For each project you can choose which Claude account it uses, the mode new Claude sessions start in, and terminals that open with it, such as a dev server.

Aliases and vocabulary

Optional. Other names for the same project, and words Claude often uses in it, such as Prisma or Next.js. They help most if you use voice mode.

4. Start VibePit

  1. Choose type or talk. The microphone is on when you first start. If you only want to type, turn it off first in Voice & listening → Microphone. Nothing else needs to download then. You can turn it on at any time later.
  2. Press Start on the Overview. VibePit starts in the background, and its logo appears in the menu bar.
  3. If the microphone is on, macOS asks once whether VibePit may use it; press Allow. The first time, the speech models download, which can take a few minutes.

5. Your first task

  1. Open a project. In the Chat, type open abc, using the name of one of your projects. VS Code opens the project with a Claude tab called abc-claude, and the tab appears in the Chats list.
  2. Tell Claude what to do. Write it in your own words in the message box, for example why is the login test failing?
  3. Follow along, or do something else. The Chat shows what Claude is doing while it works: the files it reads and edits, and the commands it runs. You do not need to watch it.
  4. Answer when Claude asks. If Claude has a question or needs your permission, the request appears in the Chat with buttons, and the tab shows that it needs you. Answer with one click. You can also answer from your phone.
  5. Read the result. When Claude finishes, VibePit tells you. The answer starts with a one-line headline, with its pull request and checks right under it, and replies you can send with one click.

Everyday use

The Chat

The Chat shows each Claude tab’s conversation, what Claude is doing right now, and its answers. Questions, permission requests and plans appear there with buttons to answer. Press ⌘K to jump to the message box.

Several projects at once

Every Claude tab in every project is in the Chats list, and each shows whether it is working, ready or needs you. Type in abc, … to send a message to another open project without leaving the one you are in.

Plans

In plan mode, a plan opens beside the Chat, laid out like a document. Approve it, or write what should change; press Shift+Return for a new line. You can also pin a plan or branch it into a new session.

Reply, copy and links

Press Reply on one answer to talk about just that answer. When Claude writes a message for someone, Copy the message to … copies it ready to paste. Links from an answer, such as pull requests and reviews, sit under its headline.

Modes

Each Claude tab has a mode. In plan mode, Claude researches and proposes a plan before it changes any files. In accept edits mode, it edits files without asking each time. You can change the mode from the Chat.

Command or message?

VibePit works out whether you typed a command, such as open abc, or a message for Claude. To be sure, begin with Pit, … for a command, or with Claude, … for a message. If a sentence could mean two things, VibePit asks you.

Floating panel

While VibePit is in the background, a small panel shows whether each Claude tab is ready, working or needs you. Click it to go back to that conversation.

Catch up

When you come back, a card in the Chats list explains what each Claude tab did while you were away.

Usage

The Chat shows how much of your 5-hour and weekly Claude limits you have used, and how full the conversation is. Your week shows the last 7 days for each project.

Notes and reminders

Pin an answer, or keep notes, checklists and reminders on one board. Claude can suggest one when you ask for a plan or a reminder; nothing is saved until you approve it.

On your phone

Your phone can use VibePit in its web browser, with nothing to install. It can send messages, answer Claude, stop a tab, attach photos, and show background tasks and changes.

  1. Make a QR code. Open On your phone in VibePit, choose one project or every project, and press Make a QR code. You can also press the phone icon in the message box.
  2. Scan it. Point your phone’s camera at the code and open the link. Each code works once, for two minutes.
  3. Press Allow on the Mac. The phone waits until you let it in. Then it shows your Claude tabs.
  4. Open it again later. If you close the page on your phone, click Scan to open again beside the phone on the Mac for a new code. You can also add VibePit to your phone’s Home screen.
On Wi-Fi

By default, the phone and the Mac need the same Wi-Fi. The link stays on your network but is not encrypted, so use a network you trust.

Anywhere

Choose Anywhere to connect from outside, through an encrypted Cloudflare link. Install Cloudflare’s free cloudflared on the Mac first: brew install cloudflared.

Who is in

Disconnect a phone from the Mac or from the phone at any time, give it a time limit, or remember it on your Wi-Fi.

Useful commands

Type these in the Chat. Anything that is not a command goes to Claude as a message. The app’s Voice commands page lists every command.

open abc

Opens the project in VS Code, with its Claude tab.

in abc, check my last change

Sends the message to that project’s Claude tab.

plan the Prisma upgrade

Claude first researches and proposes a plan, before it edits anything.

/review 42

Claude reviews that pull request with your own review instructions.

is abc done?

Tells you what that Claude tab is doing.

what did abc change?

Tells you which files are not committed, and whether commits are waiting to be pushed.

resume abc

Continues that tab’s last Claude conversation.

/

Shows Claude’s slash commands and skills, with suggestions as you type.

Voice mode (optional)

If you like, you can talk to VibePit instead of typing, and hear short summaries when Claude is done or needs you. Everything below is optional, and all of it works on your Mac.

Talk instead of typing

With the microphone on, start with Hey Pit, then say a command or a message, such as Hey Pit, open abc. For 30 seconds after each command, you can keep talking without the name.

Spoken summaries

You hear abc-claude is done with a short summary of what Claude did, or abc-claude needs you when it waits. Choose what is read aloud in Voice & listening → Reading aloud.

Your own words

Built-in rules understand the common phrases from the start. To put things any way you like, download the optional understanding model (about 1.8 GB) in Voice & listening → Understanding. It runs on your Mac.

Only my voice

Say Hey Pit, learn my voice and read five short sentences. VibePit then ignores other people speaking near you. It helps, but it is not a lock: a recording of you, or a very similar voice, can still pass.

Check before sending

If you prefer, what you say is placed in the message box first. You can correct any misheard words and then press Return.

Better hearing

Add your own Deepgram key in Voice & listening → Microphone for faster and more accurate speech recognition.

Dictation

Say dictate to type into any app, such as Slack or your browser. This needs the Accessibility permission: System Settings → Privacy & Security → Accessibility.

A different name

Say Hey Pit, change your name to Friday, or change it in Voice & listening → Name & waking. Short, distinct names are recognised best.

Other extras

A second Claude account

Add it on the Claude accounts page, then choose it for the projects that should use it. If one account is close to its limit, VibePit offers to move the conversation to the other.

Theme

Choose Dark, Light or System in General → Appearance.

Your settings

Settings are on three pages: Claude behaviour, General and Voice & listening. Each page is divided into tabs, such as Reviews, Updates or Microphone. To find a setting quickly, type a word from it in the Find a setting box at the top of the page. If the setting is on another page, a link takes you there.

Your privacy

There is no VibePit account. Your messages to Claude go through your own Claude Code, as they would if you typed them in the terminal. The app only talks to itself on 127.0.0.1, and every request needs a secret token. If you use voice mode, your speech is turned into text on your Mac, and the optional understanding model runs on your Mac too. No audio or words leave your Mac, unless you add your own Deepgram key; then only what you say to VibePit is sent to Deepgram, after it hears its name.

If something goes wrong

Claude’s questions do not appear in the Chat

Restart your Claude tabs after you install VibePit. If the Overview says the alerts are missing, press Install alerts there. This works in the Claude tabs that VibePit opened, while VibePit is running.

Claude opens in Terminal, not in VS Code

In VS Code, open the command palette with ⌘⇧P and run Developer: Reload Window. Then try again.

My phone does not connect

Check that the phone is on the same Wi-Fi as the Mac, or choose Anywhere. A code works once, for two minutes, so make a new one if it has run out. If the phone says the code is in use, another phone has it; make a new code for this one.

VibePit stopped

On the Overview, press Show log to see why, and then press Start again.

macOS says it cannot check the app

Open System Settings → Privacy & Security, scroll down, and press Open Anyway next to VibePit. You only need to do this once.

Voice mode: it does not hear me, or it reacts to noise

Check that the microphone is allowed in System Settings → Privacy & Security → Microphone. The Mic threshold setting in Voice & listening → Microphone changes how loud speech must be before VibePit listens.

Voice mode: it mishears a project name

Right after it says that it does not know a project, say I meant abc. VibePit remembers the misheard words for next time. You can also add aliases to the project.

Updates and uninstalling

Updates

When a new version is available, VibePit tells you. Press Update now. The app installs the update and opens again, and your projects and settings are kept. To check for a new version yourself, open General → Updates and press Check now. The release notes explain what is new in each version, and the app’s What’s new page shows them too.

Uninstalling

Quit VibePit. In Terminal, run ~/.vibepit/app/.venv/bin/python ~/.vibepit/app/install_hooks.py --remove to remove VibePit’s alerts from Claude Code. Then drag VibePit to the Trash, and delete the ~/.vibepit folder.
